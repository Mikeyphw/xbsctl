# Phase 31: Final Regression and Release Seal r3

Phase 31 r3 is a fail-closed release workflow for XBS Companion 4.2.0 (`versionCode` 15) and support bundle format 18.

## Security model

A release starts with a cryptographically random session ID and a private local HMAC key. The clean nested Gradle candidate build runs Android JVM tests, every `tests/test_xbs*.py` repository contract, release lint, signed release assembly, connected release instrumentation, the real Room v1-to-v2 migration test, Espresso accessibility checks, Macrobenchmark, Baseline Profile generation, and Gradle TestKit.

The HMAC-signed Gradle task/output receipt records the actual Gradle task graph, producer output paths, timestamps, sizes, and SHA-256 values. Subsequent source-audit, artifact-replay, Git, host-evidence, APK-evidence, and final-report envelopes are HMAC-bound to the same fresh session. Handwritten XML or JSON without the session receipt is therefore a blocker.

## Exact source state

`PHASE31_EXPECTED_SOURCE_TREE.json` enumerates the complete non-generated repository source tree, including all XBS Python contracts. Source audit, artifact replay, and Git finalization each require the exact path set and hashes. An extra committed or ignored Java/Kotlin/Python source is a blocker.

## APK and profile verification

The final APK must have exactly one current signer, equal to the configured SHA-256 fingerprint. The packaged evidence asset must be byte-for-byte equal to the canonical host-evidence serialization. `baseline.prof` and `baseline.profm` must match the clean candidate hashes, carry the ART profile header, and the configured AOSP `profgen` executable must strictly parse the final profile against the APK and expose generated XBS descriptors.

## Freshness

The app and host finalizer reject evidence older than six hours, evidence predating the release session, future-dated evidence, version/source/session mismatch, missing or extra gates, and malformed top-level PASS envelopes.

## Authoritative task

```bash
"$HOME/.cache/devtool/gradle-build/gradle/gradle-9.7.1/bin/gradle" --no-daemon --stacktrace \
  -Pphase31Overlay=/absolute/phase31-r3-overlay.zip \
  -Pphase31Baseline=/absolute/mike-cli-suite-20260802-192532.tar.gz \
  -Pphase31Profgen=/absolute/path/to/profgen \
  phase31FinalReleaseSeal
```

The release is approved only when `build/phase31/final-release-seal.json` is a fresh, signed, 14/14 PASS generated by that task. Source-only or sandbox validation never substitutes for the real Gradle, SDK, device, signing, benchmark, profile, or `profgen` run.


## Gradle 9.7.1 entry point

Do not run plain `gradle` if your PATH points to Gradle 8.x. AGP 9.3.1 requires Gradle 9.5.0 or newer; this project pins the fleet baseline to 9.7.1. Use Devtool's pinned Gradle when the wrapper is absent:

```bash
export GRADLE="$HOME/.cache/devtool/gradle-build/gradle/gradle-9.7.1/bin/gradle"
"$GRADLE" --version
"$GRADLE" --no-daemon --stacktrace \
  -Pphase31Overlay="$HOME/Downloads/mike_cli_suite_xbs_android_phase31_r3c_rebased_baseline_profile_hotfix_overlay.zip" \
  -Pphase31Baseline="$HOME/Downloads/mike-cli-suite-20260802-192532.tar.gz" \
  phase31FinalReleaseSeal
```
