# UI03 — generation-bound configuration and list transactions

The merged UI02 source is pinned to PR40 and its successful main-push run. UI03 requires exact raw-byte config and list preimages before a privileged editor save, checks under the transaction lock and again before promotion, refuses aliases and nonregular files, and validates journal originals and staged data before rollback/recovery. A pre-promotion conflict is never treated as a partially applied write. Config load is read-only: missing configuration requires explicit initialization. An existing target list not captured in the reviewed draft cannot be overwritten by an event rename. Reopening the target editor is required to review it. Single-operation editor guard and a single save confirmation are retained. The Linux Java shell-generation harness executes generated transactions only in a temporary unprivileged directory with stubbed daemon validation and sync; Android and rooted-device execution are separate gates. This is not protection against arbitrary concurrent noncooperating privileged filesystem changes, nor a claim of atomic multi-file replacement or durable power-loss recovery. Original 131-case matrix stays unchanged. Complete accessibility, landscape, authorized Tasker host and physical-device acceptance remain open.
